# 🐶 AI Dog Breed Classification System

🚀 An end-to-end Deep Learning based Dog Breed Classification System built using TensorFlow, FastAPI, Streamlit, Docker, and CI/CD automation.

This project evolved from a simple CNN model into a production-style AI inference system with:

* ⚡ FastAPI backend
* ⚡ Interactive Streamlit frontend
* ⚡ Dockerized deployment
* ⚡ Automated CI/CD workflows
* ⚡ Cloud deployment
* ⚡ AI-powered development workflows

---

# ✨ Features

✅ CNN + Transfer Learning based Dog Breed Classification
✅ Single & Batch Image Prediction
✅ Confidence Score Generation
✅ Breed Information Retrieval
✅ FastAPI-powered AI Backend
✅ Interactive Streamlit Frontend
✅ Dockerized Frontend & Backend
✅ Automated CI/CD Pipeline
